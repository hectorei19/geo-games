# Geo Games

Home page for three daily geography games, live at https://hectorei19.github.io/geo-games/

- Borderline: https://hectorei19.github.io/borderline/
- Connections: https://hectorei19.github.io/connections/
- Top 10: https://hectorei19.github.io/top10/

One self-contained `index.html` with Borderline's colours and fonts. "Played today" reads the same saves as the games' `games.js` menu, so it only works on the live site (same origin as the games).
